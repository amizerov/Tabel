# ChangeLog

# Реализованные изменения по ТЗ 1.5

**Проект:** «Толя табель»  
**Дата:** 16.08.2026  
**Версия приложения:** 1.0.3

По основной бизнес-логике текущий код **в целом соответствует ТЗ 1.5**.

Уже реализованы:

- обработка только заявленных смен;
- отсутствие изменений для незаявленных дней;
- красная диагностика заявленной смены при отсутствии разрешённых отметок СКУД;
- красная диагностика заявленной смены, если сотрудник не найден в СКУД;
- оранжевая диагностика неоднозначного ФИО;
- одна разрешённая отметка = `2 часа` + сине-голубой цвет + комментарий;
- расчёт по первой и последней разрешённой отметке минус 1 час;
- округление по порогу 50 минут;
- защита от отрицательного результата;
- новая логика сравнения по направлению расхождения;
- отсутствие зелёной подсветки в сравнении;
- сохранение заявленных часов, если СКУД больше заявленного;
- жёлтая подсветка, если СКУД меньше заявленного;
- сохранение специальных красных, голубых и оранжевых статусов;
- запрет сравнивать файл сам с собой;
- проверка выбранных файлов;
- разделение интерфейса на заполнение и сравнение;
- отображение версии приложения из сборки.

Оставшиеся отличия и необходимые технические доработки перечислены в актуальном файле `ТЗ_Diff.md`.
